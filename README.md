# TimeDisplacement

製作者：Panko200  
配布場所：https://github.com/panko200/TimeDisplacement

## 概要

YukkuriMovieMaker4 にて、入力した画像の輝度をもとに、アニメーションに時間差を生み出すことができるようになる映像エフェクトプラグインです。

## 使用方法

1. プラグインをインストールして YMM4 を起動する。
2. 任意のテクスチャの存在するアイテムを追加する。
3. そのアイテムを動かすやらなんやらしてアニメーションさせておく。
4. 「タイムディスプレイスメント」という映像エフェクトをかける。

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `TimeDisplacement` という名前のフォルダを削除する。

## 注意点

OS : Windows 11 (64bit)  
ゆっくりMovieMaker4 : v4.55.1.1  
CPU : Ryzen 7 9700X  
GPU : NVIDIA Geforce RTX 4070 Ti  
RAM : DDR5 64GB  
にて動作確認をしています。

### 運用上の注意

もしこのエフェクトでVRAM 1GBを超える記憶が必要になった場合は、処理を減らしてVRAMの消費を抑えます。
